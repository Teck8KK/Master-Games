# Master-Games

Site em formato de catálogo de jogos, desenvolvido como trabalho da faculdade.

A ideia é reunir jogos em um só lugar e mostrar as informações de cada um (nome, imagem, descrição, gênero e outros detalhes) de um jeito organizado e fácil de navegar.

## Como funciona

O site é feito com as três tecnologias básicas da web:

- **HTML** – estrutura das páginas e o conteúdo em si
- **CSS** – toda a parte visual: cores, layout, responsividade
- **JavaScript** – a parte interativa, como navegação, busca e exibição dos jogos

Por ser um projeto só de front-end, não precisa instalar nada nem rodar servidor.
